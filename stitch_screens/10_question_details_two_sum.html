Implementation & Notes
lightbulb Approach & Intuition
Use a single-pass hash map (dictionary) storing complement = target - nums[i]. If the complement exists in the map, return indices immediately. Eliminates O(N┬▓) brute force.
terminal Code Solution (Python 3) 
def twoSum(nums: list[int], target: int) -> list[int]:
    prev_map = {} # val -> index
    for i, n in enumerate(nums):
        diff = target - n
        if diff in prev_map:
            return [prev_map[diff], i]
        prev_map[n] = i
    return []

speed

O(N) - Hash map
warning Watch out for using the exact same element twice (e.g., target = 6 with nums = [3, 2, 4]). Single-pass avoids self-pairing naturally.
